# SIPERATA (Sistem Informasi Pelayanan & Tracking Surat Pengantar RT Online)
Aplikasi pelayanan surat pengantar RT berbasis web untuk memudahkan warga mengajukan surat dan memantau status secara real-time.

## Cara Menjalankan Aplikasi
1. Jalankan web server (Apache/MySQL) pada Laragon 5.
2. Tempatkan folder proyek di `C:\laragon\www\pemweb-obe`.
3. Buka browser dan akses `http://localhost/pemweb-obe/`.

## Catatan Fitur Selesai
- [x] Struktur dasar antarmuka HTML5 semantik (`index.html`).
- [x] Fitur navigasi dan aksesibilitas keyboard (Tab navigation).
- [x] Form kontak sekretariat RT.
