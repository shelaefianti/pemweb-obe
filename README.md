## Deskripsi Proyek
Repository ini merupakan bagian dari praktikum mata kuliah Pemrograman Web Modul 01. Praktikum membahas orientasi OBE, arsitektur web, HTTP/HTTPS, Browser Developer Tools, Git/GitHub, dan etika penggunaan AI dalam pengembangan perangkat lunak web.

## Teknologi
- HTML5
- Git
- GitHub
- Laragon 5
- Visual Studio Code
- PHP 8.4

## Cara Menjalankan Proyek
1. Jalankan Laragon 5.
2. Klik Start All untuk menjalankan Apache.
3. Pastikan folder proyek berada di:
   `C:\laragon\www\pemweb-obe`
4. Buka browser.
5. Akses alamat:
   `http://localhost/pemweb-obe/`
